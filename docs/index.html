mcf5407 C ABI Reference

This reference specifies the public C application binary interface (ABI) exposed by mcf5407 via include/mcf5407.h. It defines the low-level contracts for embedding the Motorola ColdFire MCF5407 processor core and Philips ISP1181 USB Full-Speed device controller model in C and C++ hosts.

Architectural Principles

The library exports symbols with cdecl linkage and C calling conventions. It is designed to cleanly separate the host board model from the processor core.

  • Opaque Context Objects: Pointers (mcf5407_ctx*, isp1181_ctx*) are opaque; internal fields are never exposed.
  • Primitive Types Only: The boundary transports only fixed-width integers (uint8_t, uint32_t, size_t), flat byte buffers, and function pointers.
  • No Managed Runtime Leakage: No garbage-collected references, closures, or C++ vtables cross the ABI.
  • No Thrown Exceptions: Faults and status are communicated via return codes or explicit out-parameters.
  • Diagnostic Attributes: Critical functions are annotated with MCF5407_MUST_CHECK / MCF5407_MUST_USE ([[nodiscard]] / warn_unused_result) to prevent silent error drops.

Runtime Initialisation

MCF5407_MUST_CHECK int mcf5407_runtime_init(void);

Initialises the library runtime once. This function is idempotent, thread-safe, and never aborts or terminates the host process.

Returns: 1 on success, or 0 if an initialisation latch timed out or failed. If initialisation fails, subsequent allocation calls safely return NULL.

ColdFire MCF5407 CPU Core: Context & Status

typedef struct mcf5407_ctx mcf5407_ctx;

typedef enum {
    MCF5407_BUS_OK           = 0, /* Access completed normally */
    MCF5407_BUS_UNMAPPED     = 1, /* Target address is unmapped */
    MCF5407_BUS_SIZE_ILLEGAL = 2, /* Target rejects access width */
    MCF5407_BUS_FAULT        = 3  /* Target asserts bus error */
} mcf5407_bus_status;

Memory & Interrupt Callbacks

The host board implements address decoding and supplies callbacks during CPU context creation: 

typedef uint32_t (*mcf5407_read_fn)(void* user, uint32_t addr, int size,
                                    mcf5407_bus_status* status);

typedef void (*mcf5407_write_fn)(void* user, uint32_t addr, int size,
                                 uint32_t value, mcf5407_bus_status* status);

typedef void (*mcf5407_iack_fn)(void* user, int level, uint8_t vector);

size is the access width in bytes (1, 2, or 4). status is an out-parameter pre-initialised to MCF5407_BUS_OK. mcf5407_iack_fn is called during interrupt acknowledge cycles after pushing the exception frame.

Lifecycle Management

mcf5407_ctx* mcf5407_create(void* user,
                            mcf5407_read_fn rd,
                            mcf5407_write_fn wr,
                            mcf5407_iack_fn iack);

void mcf5407_destroy(mcf5407_ctx* ctx);

void mcf5407_reset(mcf5407_ctx* ctx, uint32_t initial_sp, uint32_t initial_pc);

mcf5407_reset sets the stack pointer (A7) to initial_sp, the program counter (PC) to initial_pc, the interrupt priority mask in SR to 7, clears all control registers to zero, and inhibits interrupt sampling for the initial instruction.

Instruction Execution

uint32_t mcf5407_exec(mcf5407_ctx* ctx, uint32_t max_cycles);

Executes instructions until at least max_cycles cycles have elapsed. Because the cycle limit is evaluated at instruction boundaries, the returned count may exceed max_cycles by up to the cost of the final instruction. Schedulers should carry spent - max_cycles forward into the next quantum.

Execution State

int mcf5407_halted(const mcf5407_ctx* ctx);
int mcf5407_faulted(const mcf5407_ctx* ctx);

mcf5407_halted returns 1 if the CPU has stopped. mcf5407_faulted returns 1 if the stop was caused by a processor fault (bus error, illegal instruction, unaligned access, or divide by zero). All faulted cores are halted.

Interrupt Presentation

#define MCF5407_IRQ_NONE 0

void mcf5407_set_irq(mcf5407_ctx* ctx, int level, uint8_t vector, int autovector);

Presents the board's current highest pending interrupt. Levels 1 to 6 are level-sensitive. Level 7 is non-maskable and edge-triggered; the core latches a rising edge to level 7.

State Serialization

size_t mcf5407_state_size(void);
void mcf5407_state_save(const mcf5407_ctx* ctx, void* dst);
void mcf5407_state_load(mcf5407_ctx* ctx, const void* src);

Saves and loads the CPU core state to/from a flat, self-contained, versioned binary block.

Philips ISP1181 USB Controller: Context & Callbacks

typedef struct isp1181_ctx isp1181_ctx;

typedef void (*isp1181_irq_fn)(void* user, int asserted);
typedef void (*isp1181_tx_fn)(void* user, int endpoint,
                              const uint8_t* data, size_t len);

isp1181_irq_fn reports logical interrupt assertion (active high). isp1181_tx_fn is called synchronously when an IN packet is transferred to the USB host.

Lifecycle & Backends

isp1181_ctx* isp1181_create(void* user, isp1181_irq_fn irq, isp1181_tx_fn tx);

#define MCF5407_ISP1181_BACKEND_STUB       0
#define MCF5407_ISP1181_BACKEND_FULL_MODEL 1

int isp1181_set_backend(isp1181_ctx* ctx, int backend);

The default mode is MCF5407_ISP1181_BACKEND_STUB (passive stub). Set to MCF5407_ISP1181_BACKEND_FULL_MODEL to activate full FIFO logic and registers.

USB Packet Interface

MCF5407_MUST_USE int isp1181_rx(isp1181_ctx* ctx, int endpoint,
                                const uint8_t* data, size_t len);

int isp1181_setup(isp1181_ctx* ctx, const uint8_t* data, size_t len);

int isp1181_in_token(isp1181_ctx* ctx, int endpoint);

isp1181_rx receives an OUT packet from the host (returns 1 on accept, 0 on NAK/reject). isp1181_setup delivers a control SETUP packet to Endpoint 0. isp1181_in_token triggers transmission if data is validated in the specified endpoint's IN buffer.

SOF Timebase

void isp1181_tick(isp1181_ctx* ctx, uint32_t sof_frames);

Advances the USB frame counter by sof_frames. Each SOF frame represents exactly 1 millisecond.

Integration Example: C Host

#include <stdio.h>
#include <string.h>
#include "mcf5407.h"

#define RAM_SIZE 0x100000
static uint8_t s_ram[RAM_SIZE];

static uint32_t board_read(void* user, uint32_t addr, int size, mcf5407_bus_status* status) {
    if (addr + size <= RAM_SIZE) {
        uint32_t val = 0;
        for (int i = 0; i < size; ++i) val = (val << 8) | s_ram[addr + i];
        return val;
    }
    *status = MCF5407_BUS_UNMAPPED;
    return 0;
}

static void board_write(void* user, uint32_t addr, int size, uint32_t val, mcf5407_bus_status* status) {
    if (addr + size <= RAM_SIZE) {
        for (int i = size - 1; i >= 0; --i) {
            s_ram[addr + i] = (uint8_t)(val & 0xFF);
            val >>= 8;
        }
        return;
    }
    *status = MCF5407_BUS_UNMAPPED;
}

static void board_iack(void* user, int level, uint8_t vector) {
    (void)user; (void)level; (void)vector;
}

int main(void) {
    if (!mcf5407_runtime_init()) return 1;

    mcf5407_ctx* cpu = mcf5407_create(NULL, board_read, board_write, board_iack);
    if (!cpu) return 1;

    mcf5407_reset(cpu, 0x00080000, 0x00000400);
    uint32_t spent = mcf5407_exec(cpu, 1000);
    printf("Executed %u cycles; halted=%d\n", spent, mcf5407_halted(cpu));

    mcf5407_destroy(cpu);
    return 0;
}

Integration Example: C++ Host

#include <iostream>
#include <vector>
#include <stdexcept>
#include "mcf5407.h"

class SystemBoard {
public:
    SystemBoard() {
        if (!mcf5407_runtime_init()) {
            throw std::runtime_error("mcf5407 runtime initialization failed");
        }
        m_ram.resize(0x200000, 0);
        m_cpu = mcf5407_create(this, &SystemBoard::readThunk, &SystemBoard::writeThunk, &SystemBoard::iackThunk);
        if (!m_cpu) {
            throw std::runtime_error("mcf5407 CPU creation failed");
        }
    }

    ~SystemBoard() {
        if (m_cpu) mcf5407_destroy(m_cpu);
    }

    void reset(uint32_t sp, uint32_t pc) {
        mcf5407_reset(m_cpu, sp, pc);
    }

    uint32_t step(uint32_t cycles) {
        return mcf5407_exec(m_cpu, cycles);
    }

private:
    static uint32_t readThunk(void* user, uint32_t addr, int size, mcf5407_bus_status* status) {
        return static_cast<SystemBoard*>(user)->handleRead(addr, size, status);
    }

    static void writeThunk(void* user, uint32_t addr, int size, uint32_t val, mcf5407_bus_status* status) {
        static_cast<SystemBoard*>(user)->handleWrite(addr, size, val, status);
    }

    static void iackThunk(void* user, int level, uint8_t vector) {
        (void)user; (void)level; (void)vector;
    }

    uint32_t handleRead(uint32_t addr, int size, mcf5407_bus_status* status) {
        if (addr + size <= m_ram.size()) {
            uint32_t val = 0;
            for (int i = 0; i < size; ++i) val = (val << 8) | m_ram[addr + i];
            return val;
        }
        *status = MCF5407_BUS_UNMAPPED;
        return 0;
    }

    void handleWrite(uint32_t addr, int size, uint32_t val, mcf5407_bus_status* status) {
        if (addr + size <= m_ram.size()) {
            for (int i = size - 1; i >= 0; --i) {
                m_ram[addr + i] = static_cast<uint8_t>(val & 0xFF);
                val >>= 8;
            }
            return;
        }
        *status = MCF5407_BUS_UNMAPPED;
    }

    mcf5407_ctx* m_cpu{nullptr};
    std::vector<uint8_t> m_ram;
};
